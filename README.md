# Monthly Performance Review Template for Agency Teams

A **30–45 minute meeting script** for website performance reviews: snapshot, trends, wins, regressions, three owned actions, and a client communication summary.

**Who it's for:** Agency technical leads, account managers, delivery managers.

**What you need:** Month-over-month CWV deltas and alert history for priority URLs.

**Canonical article:** [Monthly Performance Review Template for Agency Teams](https://apogeewatcher.com/blog/monthly-performance-review-template-for-agency-teams)

**Index:** [core-web-vitals-checklists](https://github.com/Apogee-Information-Systems/core-web-vitals-checklists) · [Apogee on GitHub](https://apogee-information-systems.github.io/)

## How to use this repo
- Copy [`templates/monthly-review.md`](templates/monthly-review.md) into your docs tool.
- Run **New issue → Monthly performance review** for one tracked run per client/month.
- Pair with [performance-review-meeting-agenda](https://github.com/Apogee-Information-Systems/performance-review-meeting-agenda) for timeboxing, and [client-cwv-report-outline](https://github.com/Apogee-Information-Systems/client-cwv-report-outline) for the polished deliverable.

## Status labels

- **Healthy** — no high-severity regressions; core templates within thresholds
- **Needs attention** — key templates out of threshold; impact contained
- **Critical** — high-impact regressions on revenue/lead pages, unresolved across runs

## Cadence

Week 1: review + lock actions → Weeks 2–3: ship → Week 4: verify + draft next notes.
